# Bundled UI assets

- Wanted Sans Regular, from https://github.com/wanteddev/wanted-sans at `02c9b822349c188ada95f9e2d90c2ed18f853235`. License: `fonts/OFL.txt`.
- Gravity Icons SVGs, from https://github.com/gravity-ui/icons at `5fade87690de42eca78b419e2509df39b325517d`. License: `icons/LICENSE`. The Pen tool embeds `svgs/pencil.svg` as `icons/pen.svg`.

Assets are embedded in the desktop executable; no network or system font installation is required at runtime.
